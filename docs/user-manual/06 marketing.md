# التسويق

وحدة التسويق متاحة لمالك المزرعة والمحاسب ومدير المزرعة. افتح **التسويق** من القائمة.

## الشاشة الرئيسية

ابدأ من **نظرة عامة**. ستجد عدد جهات الاتصال، والسجلات النشطة، والمتابعات القريبة. استخدم الروابط للانتقال إلى:

1. **المنتج:** دفعات الجودة والكميات الأسبوعية المتاحة.
2. **الأسواق:** أسعار السوق والمنافسون ومتابعة موزعي الكويت.
3. **خط المبيعات:** العملاء المحتملون وعروض EXW والوسطاء.
4. **الحملات:** جهات الاتصال والمهام والمنصات والشهادات والأهداف وقوالب الرسائل.

## استيراد ملف تسويق 2026

1. من نظرة عامة، اضغط اختيار ملف وحدد ملف JSON القديم.
2. اضغط **معاينة**.
3. راجع الأعداد والمفاتيح المرفوضة. النظام يتجاهل مفاتيح التطبيقات الأخرى ولا يستورد سجل الحصاد القديم.
4. إذا كانت المعاينة صالحة، اضغط **استيراد السجلات المقبولة**.
5. يمكن إعادة استيراد الملف نفسه. السجلات الموجودة تُحدّث ولا تتكرر.

القوائم الكبيرة في الملف الأصلي تبقى أعدادًا مرجعية فقط. النظام يستورد الحالة المحفوظة والمختارة، وليس كامل قائمة جهات الاتصال غير المنقحة.

## إضافة سجل أو تعديله

1. افتح القسم المناسب.
2. اضغط **إضافة**.
3. اكتب الحقول المطلوبة ثم احفظ.
4. اضغط **تعديل** لتغيير سجل موجود، أو **أرشفة** لإخفائه دون حذفه نهائيًا.
5. استخدم البحث للوصول إلى السجل بسرعة، و**إظهار المؤرشف** لاستعادته.

## جهات الاتصال والمتابعة

جهات الاتصال التسويقية منفصلة عن العملاء في المحاسبة. من الحملات يمكنك إضافة جهة اتصال أو تعديلها، ثم فتح **النشاط** لتسجيل مكالمة أو بريد أو اجتماع أو موعد متابعة.

## قوالب الرسائل

أضف نص الرسالة كقالب ثم اضغط **نسخ**. النظام لا يرسل بريدًا أو واتساب تلقائيًا؛ راجع النص وأرسله يدويًا من تطبيقك.
